SQL 語法 專題問卷對應之關聯式資料庫（SQL）語法對照

在真實的資料庫管理系統（如 MySQL、PostgreSQL）中，您可以使用以下標準 SQL 語法來建立和處理本問卷的數據：

1. 建立問卷回覆資料表 (CREATE TABLE) 
CREATE TABLE submissions (
    id VARCHAR(50) PRIMARY KEY, -- 唯一回覆識別碼
    submitted_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP, -- 提交時間
    gender VARCHAR(10) NOT NULL, -- Q1: 性別
    education VARCHAR(20) NOT NULL, -- Q2: 學歷
    frequency VARCHAR(30) NOT NULL, -- Q3: 網購頻率
    platform VARCHAR(20) NOT NULL, -- Q4: 最愛用平台
    category VARCHAR(30) NOT NULL, -- Q5: 最常買商品
    avg_spend VARCHAR(30) NOT NULL, -- Q6: 平均消費金額
    payment_methods TEXT NOT NULL, -- Q7: 付款方式 (多選，以 CSV 儲存)
    attract_reason VARCHAR(30) NOT NULL, -- Q8: 平台吸引因素
    delivery_rating INT NOT NULL, -- Q9: 物流滿意度 (1-5分)
    feedback TEXT -- Q10: 未來期待/建議
);
2. 新增受試者回覆紀錄 (INSERT INTO) 
INSERT INTO submissions (id, gender, education, frequency, platform, category, avg_spend, payment_methods, attract_reason, delivery_rating, feedback)
VALUES ('sub-001', '女性', '大學學生', '每周一次', '蝦皮', '衣服鞋子與穿搭配件', '新台幣 301 - 1,000元', '超商取貨付款, 行動支付', '免運費活動頻率高', 4, '希望包裝可以更環保！');
3. 查詢統計消費者「最愛用平台」的投票率與得票數 (SELECT & GROUP BY) 
SELECT 
    platform AS '購物平台',
    COUNT(*) AS '得票總數',
    ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM submissions), 2) AS '投票率 (%)'
FROM submissions
GROUP BY platform
ORDER BY 得票總數 DESC;

📊 試算表雲端連動設定（超簡單 5 步）

  1. 建立試算表： 在 Google 雲端硬碟建立一個新的試算表。
  2. 開啟 Apps Script 選單： 點擊試算表頂部選單的「延伸功能」>「Apps Script」。
  3. 貼上並儲存接收端程式：

    將預設的程式碼清空，並貼上下方代碼：

    function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var params = JSON.parse(e.postData.contents);
  var rowData = [
    new Date(), // 填寫時間
    params.f1, params.f2, params.f3, params.f4, params.f5,
    params.f6, params.f7 ? params.f7.join(', ') : '', params.f8, params.f9, params.f10
  ];
  sheet.appendRow(rowData);
  return ContentService.createTextOutput(JSON.stringify({"status":"success"})).setMimeType(ContentService.MimeType.JSON);
}
  4. 發布網頁應用程式： 點選右上角「部署」>「新增部署」，類型選「網頁應用程式」，將「誰有權限存取」設定為「所有人 (Anyone)」，點選部署。
  5. 完成網址綁定： 複製部署成功的網頁應用程式網址，並貼回到本系統的「SQL 資料庫管理」設定欄位中。
